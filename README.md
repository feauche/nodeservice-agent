# nodeservice-agent

Агент NodeService для сервера: один статический Go-бинарь, который отдаёт панели
heartbeat и метрики CPU, памяти, диска, сети, conntrack, load, uptime и состояние
Xray. Начиная с v0.8.0 панель сама опрашивает агент по HTTPS, как Remnawave
опрашивает ноды. Серверу не требуется доступ к домену панели.

Это отдельный git-репозиторий со своими GitHub Releases:
`nodeservice-agent_linux_amd64`, `nodeservice-agent_linux_arm64`, `checksums.txt`
и `install.sh`.

## Установка из панели

Панель сама:

1. Выбирает постоянный пятизначный порт 10000–65535. Уникальный индекс PostgreSQL
   не позволяет назначить один порт двум серверам, а SSH-проверка исключает
   столкновение с другой службой на самом сервере.
2. Создаёт отдельный случайный ключ доступа для сервера и хранит его в базе
   зашифрованным AES-256-GCM.
3. Передаёт ключ установщику через stdin. Ключ не появляется в SSH-команде,
   списке процессов или журнале systemd.
4. Агент создаёт собственный сертификат Ed25519. Панель получает открытый
   сертификат по доверенному SSH-сеансу и затем принимает только его.
5. Добавляет в UFW правило только для IP панели и выбранного TCP-порта. Если UFW
   выключен, правило подготавливается, но установщик не включает UFW сам: иначе
   можно случайно закрыть действующие VPN- и SSH-порты.

Состояние и закрытые ключи лежат в `/var/lib/nodeservice-agent` с правами 0600.
При смене IP самого сервера достаточно изменить адрес в NodeService: ключ,
порт и сертификат сохраняются. Если изменился внешний IP самой панели,
нужно ещё раз запустить «Обновить агента», чтобы UFW разрешил новый адрес.

Старый исходящий WebSocket и подписанный HTTPS pulse остаются в бинаре для плавного
обновления уже установленных агентов. Новая автоматическая установка сразу
переводит сервер на входящий режим.

## Протокол входящего канала

Панель раз в 10 секунд выполняет `GET /v1/snapshot` по TLS 1.3. Защита состоит из
двух независимых частей:

- уникальный Bearer-ключ аутентифицирует панель;
- закреплённый сертификат аутентифицирует агент и не позволяет подменить ответ.

API только для чтения и не выполняет команды. Частота записи метрик по-прежнему
задаётся в настройках NodeService. Старый протокол v1 описан в
`panel/packages/shared/src/agent-protocol.ts`.

## Разработка

```sh
make test
make vet
make build
make build-all VERSION=v0.8.0
```

## Структура

```text
main.go, cmd_run.go, cmd_configure_pull.go — CLI и выбор режима
internal/pull       — HTTPS API, TLS-сертификат и проверка ключа
internal/metrics    — сбор системных метрик
internal/state      — state.json с атомарной записью и правами 0600
internal/enroll     — совместимость со старой регистрацией
internal/transport  — совместимость со старым WebSocket/HTTPS pulse
deploy/             — systemd-юнит
scripts/install.sh  — установка и правило UFW
```
